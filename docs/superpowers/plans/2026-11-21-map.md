# Map & fast travel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A chapter map on C (rebindable) showing visited/revealed rooms and icons, with fast travel between lit Bell Shrines.

**Architecture:** Pure layout/selection logic in `src/game/map.ts` (tested). A `MapScreen` overlay in `src/ui/map-screen.ts` owned by the game scene (like the dialogue box). Quill's reveal is a choice `effect` collected by `Conversation`. Fast travel is a short timed transition in the game scene.

**Tech Stack:** TypeScript, canvas (offscreen cache), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-21-map-design.md`

## Global Constraints

- MAP action default `KeyC`, label "MAP" in CONTROLS; PAUSE menu gains "MAP".
- 2 px per tile; visited = silhouette, revealed = outline, unknown = hidden.
- Travel only at a shrine, alive, grounded; destinations = lit shrines other than the current one.
- Save gains optional `revealed: string[]` (format stays v1).
- Commits plain, no attribution; branch `feature/map`.

## Review Focus

1. Opening the map at a shrine when it is the only lit shrine → browse mode, no travel prompt. Test in Task 1 (`travelTargets` empty).
2. Map key pressed during a conversation, rewind, transition or death → ignored. Task 3 guard.
3. Old saves without `revealed` load fine. Task 3 (default `[]`).
4. Travelling saves at the destination (CONTINUE resumes there). Task 3 browser check.
5. Rebinding MAP onto another key swaps (existing `rebind`); old settings get C. Test in Task 2.

### Task 1: Map logic + conversation effects

**Files:** create `src/game/map.ts`, `src/game/map.test.ts`; modify `src/game/dialogue.ts` (+test).

**Produces:**
```ts
export interface MapRoom { name: string; x: number; y: number; w: number; h: number } // tiles, world coords
export type CellState = "visited" | "revealed" | "hidden";
export function cellState(name: string, visited: Set<string>, revealed: boolean): CellState;
export function mapBounds(rooms: MapRoom[]): { x: number; y: number; w: number; h: number };
export interface ShrineSpot { room: string; index: number; x: number; y: number } // x,y world px
export function travelTargets(shrines: ShrineSpot[], lit: Set<string>, here: string | null): ShrineSpot[]; // lit, not "here" ("room:index"), sorted by x
// dialogue.ts: Choice.effect?: string; Conversation.effects: string[] (pushed when that choice is confirmed)
```
