# Save system Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3 local save slots, auto-saved at every crystal/shrine, with CONTINUE and a slot screen.

**Architecture:** `src/game/save.ts` holds the `SaveData` format and a `SaveStore` (storage injected, testable). `Progress` gains export/restore. The game scene builds a `SaveData` on every checkpoint touch and can start a run from one. Menus pick the slot and pass it through a `session` on `Ctx`.

**Tech Stack:** TypeScript, localStorage, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-21-save-design.md`

## Global Constraints

- Keys: `echo.save.v1.slot1..3`, `echo.save.lastSlot`. `SaveData.version = 1`; anything else or unparsable = empty slot.
- Slot line: `FILE n  <ROOM TITLE>  SHARDS n  PAGES n  H:MM` or `FILE n  EMPTY`.
- Commits plain, no attribution; branch `feature/save`.

## Review Focus

1. Corrupted or old-format save in a slot → shown EMPTY, game doesn't crash. Test in Task 1.
2. localStorage blocked (private mode) → saving silently does nothing, menus still work. Test in Task 1.
3. A saved room that no longer exists → resume at the start room, progress kept. Task 3 (guard in `startRun`).
4. Continue right after a new game with no crystal touched yet → no save exists, CONTINUE hidden. Task 4.
5. Erasing the last used slot → CONTINUE disappears. Test in Task 1 (`lastSlot` cleared on erase).

### Task 1: SaveStore + format

**Files:** create `src/game/save.ts`, `src/game/save.test.ts`.

**Produces:**
```ts
export interface SaveData { version: 1; room: string; point: { x: number; y: number }; abilities: Ability[]; echoSlots: number;
  secured: [string, CollectibleKind][]; lit: string[]; lastCheckpoint: Record<string, { x: number; y: number }>;
  talked: string[]; visited: string[]; playTime: number; savedAt: number }
export const SLOTS = 3;
export class SaveStore { constructor(storage?: Pick<Storage, "getItem" | "setItem" | "removeItem"> | null);
  load(slot: number): SaveData | null; write(slot: number, d: SaveData): void; erase(slot: number): void;
  get lastSlot(): number | null; set lastSlot(n: number | null); }
export function formatPlayTime(seconds: number): string; // 2520 -> "0:42"
```
