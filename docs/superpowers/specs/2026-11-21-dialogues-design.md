# NPC dialogues (Undertale-style)

Date: 2026-11-21 · Branch: `feature/dialogues`

## Intent

Tamsin and Quill exist in chapter 0 but can't be talked to. The user wants them to
deliver the opening lore through an Undertale-like dialogue box: typewriter text with
voice blips that fit the chiptune theme. Deeper lore (the Stilling, the Tollers) is
left for later, possibly as text on the Lost Pages (noted, not built now).

## Decided (with the user)

- Content = the existing script, unchanged: SCRIPT.md §6.1 (Tamsin waking Iris, with
  the NOD / TILT HEAD choice and the repeat line) and §6.4 first meeting (Quill, with
  the WILL IT COME BACK? / SHOW ME THE MAP choice, then "MAP UPDATED").
- A new **INTERACT** action, default key **E** (`KeyE`), used for NPCs now and other
  interactables later. It is rebindable in SETTINGS → CONTROLS like every other key.
- Box per SCRIPT.md §4.6: bottom of the screen, menu-panel style, 32×32 portrait on
  the left, name in the character's colour, uppercase text at 40 characters/s.

## Behaviour

- Near a talkable character, a key prompt (the player's actual INTERACT key) floats
  above them. INTERACT opens the conversation; Iris stops (no input reaches her), the
  music ducks a little.
- Typewriter: 40 chars/s; short pause after `,` and longer after `.`, `!`, `?`, `…`.
- Voice blip every 2 typed letters (never on spaces/punctuation), per-character voice
  from the existing synth with a small random pitch wobble:
  Tamsin low and warm (triangle), Quill high and nervous (thin pulse), SYSTEM a
  neutral beep.
- JUMP or INTERACT: finish the line instantly, then next line. PAUSE: end the
  conversation. Choices: UP/DOWN to pick, JUMP/INTERACT to confirm. Choices only
  change the reply.
- First talk plays the whole script; later talks play the short repeat line (Quill's
  repeat: my call, a one-liner in his voice). Remembered for the current run (there
  is no save system yet).

## My calls (check these)

- The **Lingering villagers** (frozen people) can be talked to with INTERACT too,
  since the user said the key is for villagers as well: their one line opens in the
  box, no portrait, name "LINGERING", a faint echoing voice. Their floating text is
  replaced by the key prompt.
- Quill's repeat line: "THE MILL'S ON THE MAP NOW. THE MILL IS ALWAYS ON THE MAP."
- Portraits are placeholders generated by `tools/gen_sprites.py`, like the other art.
- The dialogue logic (typing, pauses, blips, choices, skip) is a pure class tested
  with Vitest; the box drawing and wiring are checked in the browser.

## Approaches considered

- A separate scene for dialogues: ruled out, the scene manager can't stack scenes
  and re-entering the game scene starts a new run.
- **An overlay owned by the game scene** (chosen): the game scene holds the current
  conversation, stops feeding input to Iris while it's open, and draws the box.

## Non-goals

- No map (MAP UPDATED is just a system line), no save system, no Pip hints, no
  after-chapter lines, no Lost Page lore.
